# Bpost Logistics Data Engineering Platform

## Project Overview

This project simulates a production-grade enterprise data engineering platform for logistics and transportation operations.

The platform processes parcel and fleet data to support operational monitoring, data quality, delivery performance analysis, and truck-trip management.

## Business Domains

### Parcel Operations
- Parcel announcement
- Address validation
- Sorting
- Grey-zone tracking
- Distribution
- Delivery performance

### Fleet Operations
- Trip planning
- Truck assignment
- Trailer assignment
- Truck key availability
- Planned vs actual vehicle analysis
- Truck maintenance

- Git

## Objective

Build an end-to-end, scalable and production-oriented data platform that can support large-scale batch and streaming workloads while handling data quality issues, duplicate data, late-arriving data, schema evolution and incremental processing.
